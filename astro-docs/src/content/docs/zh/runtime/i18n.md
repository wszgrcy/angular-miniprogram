title: '多语言'
---

走的是**运行时 i18n**：构建期不做 xliff 抽取，也不做 AOT 内联。模板里的 `i18n`
和 ICU 由全局 `$localize` 在运行时查译文表。

所以构建选项里没有 `localize`，也不需要按语言各构建一份产物——一份产物 + 一份译文表。

## 1. 接线

```jsonc
// angular.json -> options
{ "polyfills": ["@angular/localize/init"] }
```

**`/init` 必须写全。** 主入口不挂全局 `$localize`，只写 `@angular/localize` 构建会绿，
运行时撞 `Cannot set properties of undefined (setting 'translate')`。

```jsonc
// tsconfig.app.json
{ "compilerOptions": { "types": ["@angular/localize/init"] } }
```

否则 TS 里用 `$localize` 没有类型。

## 2. 译文表

消息一律用 `i18n="@@xxx"` 显式命名，译文表的 key 就是 `xxx`。不命名则由编译器
按文案算哈希，改一个字 id 就变，没法维护。

```ts
import { clearTranslations, loadTranslations } from '@angular/localize';

const EN: Record<string, string> = {
  'i18n.title': 'Internationalization',
  'i18n.cartCount': '{$INTERPOLATION} item(s) in the cart',
  'i18n.select': '{VAR_SELECT, select, male {he} female {she} other {they}}',
  'i18n.plural':
    '{VAR_PLURAL, plural, =0 {nothing yet} one {just one} other {{INTERPOLATION} in total}}',
};

export function applyLocale(id: 'zh' | 'en') {
  clearTranslations();          // loadTranslations 只加不减，切回去必须先清
  loadTranslations(id === 'en' ? EN : {});
}
```

`loadTranslations(translations)` **只收一个参数**，没有第二个 `locale` 参数，
多传会被静默忽略。

### 占位符名

译文里的占位符名必须与编译产物**逐字一致**，写错不报错，只会静默退回源文案。

| 源写法 | 占位符 |
| --- | --- |
| `{{ a }}` 单个插值 | `{$INTERPOLATION}` |
| 多个插值 | `{$INTERPOLATION_1}` `{$INTERPOLATION_2}` … |
| ICU `select` 的变量 | `{VAR_SELECT, select, …}`（裸写，不带 `$`） |
| ICU `plural` 的变量 | `{VAR_PLURAL, plural, …}` |
| ICU 分支里的插值 | `{INTERPOLATION}` |

ICU 那几条是 `ɵɵi18nPostprocess` 在译文求值**之后**再替换的，所以形态跟插值不同。

名字别靠猜，去产物里 grep：

```bash
grep -o '`:[^`]*`' dist/<app>/pages/i18n/i18n-entry.js
```

## 3. 生效时机（最容易踩的一条）

模板文案的译文在组件 `consts` **首次求值**时就定死了，而 `consts` 每个组件类型只求一次。
所以译文必须在该组件首次渲染之前就位。

```ts
// main.ts —— bootstrap 之前
applyLocale(readStoredLocale());
bootstrapApplication();
```

运行中切换语言只对**还没渲染过的组件**起作用，已经渲染的要重启小程序才更新。
在取值时求值的内容不受影响，比如 TS 里直接调 `$localize`：

```ts
get liveLabel() {
  return $localize`:@@i18n.live:这一行每次取值都重新求值`;
}
```

`$localize` 必须当**模板标签**用（`` $localize`…` ``）。当普通函数调用拿不到
`.raw`，内部会炸。

## 4. 模板里能用什么

| 写法 | 支持 |
| --- | --- |
| `i18n="@@id"` 静态文案 | ✅ |
| `i18n="@@id"` + `{{插值}}` | ✅ |
| ICU `{ x, select, … }` / `{ x, plural, … }` | ✅ |
| `i18n-alt` / `i18n-title` / `i18n-aria-label` 等属性 | ✅（带插值的走 `setProperty`，静态的走 `setAttribute`） |
| TS 里 `` $localize`:@@id:文案` `` | ✅ |

两条 ICU 的排版限制：ICU 前后的空白会被并进消息本体，所以带 ICU 的那行**不能折行**；
分支里也不能放标签。

```html
<!-- 这样 -->
<p i18n="@@i18n.plural">{count(), plural, =0 {还没有商品} one {只有一件} other {{{count()}} 件}}</p>
```

## 5. 语言存哪儿

小程序没有 `localStorage`，用 `wx.setStorageSync`（或 `MpApiService.setStorageSync`）：

```ts
export function readStoredLocale(): LocaleId {
  return wx.getStorageSync('demo.locale') === 'en' ? 'en' : 'zh';
}
```

也可以在 `onLaunch` 里读小程序的 `language` 作为默认值。
